# OBJECTRA

Sistema académico de detección de objetos en tiempo real.

## Construcción por etapas

Este repositorio comienza desde cero. La versión local validada sirve como referencia de comportamiento y diseño; no se importa la aplicación completa.

1. CESAR: base Django, PostgreSQL, modelo de capturas y pruebas iniciales.
2. JHOAN: detector OpenCV/Ultralytics y API.
3. JEAN: interfaz y estilos de OBJECTRA.
4. DANIELA: interacción, cámara, comparador e historial visual.
5. ISAAC: documentación y video de la versión integrada.

Cada etapa se propone mediante una rama y un pull request.
